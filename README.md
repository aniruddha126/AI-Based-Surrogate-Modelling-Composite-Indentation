# AI-Based Surrogate Modelling for Composite Laminate Indentation

**M.Tech Thesis Submitted to Indian Institute of Technology Jammu**

Repository: https://github.com/aniruddha126/AI-Based-Surrogate-Modelling-Composite-Indentation

## Overview

This repository contains the datasets, machine learning models, training notebooks, results, and thesis associated with the study:

> **AI-Based Surrogate Modelling for Composite Laminate Indentation**  
> *(Assessment of ANN, XGBoost and Random Forest Models for Advanced Material Behaviour Prediction)*

## Repository Structure

| Folder | Description |
|----------|----------|
| `thesis/` | Final dissertation and supplementary documents |
| `data/` | Raw and processed datasets |
| `notebooks/` | Jupyter notebooks used for analysis and model development |
| `models/` | Trained ANN, Random Forest, and XGBoost models |
| `results/` | Validation and independent testing results |


## Key Results

| Model | Average Validation R² |
|--------|--------|
| ANN | 0.9993 |
| Random Forest | 0.9918 |
| XGBoost | 0.9830 |
